# Project rules

This is a small website for the IT DigiLearn AI Enablement course. The person you work with is learning.

- Before changing code, show a short plan: the files you would change and why. Wait for a yes.
- Work on a branch. Never commit to main and never push to main.
- Change only the files the task names. Ask before touching any other file.
- Run the tests with `npm test`. A change is not done until every test passes.
- Never write a password, key or token into any file. Never commit `.env`.
- Never edit or delete a test to make it pass. Fix the code instead, or say why the test is wrong.
